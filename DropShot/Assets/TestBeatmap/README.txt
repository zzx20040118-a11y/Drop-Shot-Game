測試素材：120 BPM 擊打測試

音訊：test_120bpm.wav（原創合成節拍聲，30 秒，單聲道 PCM WAV）
譜面：test_120bpm.json

音訊從 0 秒開始，每 0.5 秒一拍，每四拍的第一拍為較高音。
前四拍（0、0.5、1、1.5 秒）是預備拍，不需要擊打。
譜面從 2 秒至 29.5 秒，每半秒一個擊打，共 56 個。

JSON 欄位：
formatVersion：此測試格式版本。
audioFile：配對音訊檔名，僅作識別，不會自動載入或播放。
notes[].time：從配對音訊開頭算起的擊打時間，單位為秒。
notes[].lane：0 為左軌，1 為右軌，表示這一拍的目標軌道。
notes[].type：hit 為單次擊打。

lane 目前只作測試資料，尚未決定按鍵或自動換軌規則。
此格式是本專案暫定測試格式，尚未確認與隊友的 JSON 格式相容。
Unity 需要另外的讀取、音樂同步、提示及按鍵判定程式。
這次只新增素材，沒有修改場景或現有腳本。
